# Short pipeline video checklist

Record your own 3-5 minute walkthrough. Narrate the steps:

1. Introduce the question, dataset source, and educational-use limitation.
2. Show data download and processed files.
3. Show EDA figures and explain class balance, missingness, and one limitation.
4. Show MLflow's two candidate runs, CV metrics, and selected pipeline.
5. Run tests and show the GitHub Actions workflow result.
6. Build/run Docker and call `/health`, `/predict`, and `/metrics`.
7. If using Minikube, show deployment status and API access; otherwise explain local access.
8. Close with limitations and next steps before any real clinical use.

Do not fabricate a run, screenshot, deployment, URL, or result. Keep credentials and patient data out of the recording.
